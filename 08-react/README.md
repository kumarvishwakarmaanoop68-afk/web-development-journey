## Project

A beginner React application that displays tasks, lets the user add tasks, mark tasks complete, and shows task statistics.

## Run

Install Node.js, then from the `08-react` directory run:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Learning Goal

Understand React's component-based approach and learn how state and events are used to build interactive user interfaces.
