# 🌐 Web Development Journey

My practical journey from HTML basics to full-stack web development.

## 🎯 Goal

Build strong frontend and backend skills by learning concepts, practicing regularly, and creating real projects.

## 📚 Roadmap

- **01 HTML Basics** — Structure, headings, links, images, lists, buttons, forms
- **02 CSS Basics** — Selectors, colors, typography, box model
- **03 Layout** — Flexbox, Grid, positioning
- **04 Responsive Design** — Mobile-friendly websites
- **05 JavaScript Basics** — Variables, functions, conditions, loops
- **06 DOM** — Events and dynamic webpages
- **07 JavaScript Projects** — Practical browser projects
- **08 React** — Components, props, state, hooks
- **09 Node & Express** — Backend development
- **10 Database** — MongoDB and APIs
- **11 Full-Stack Projects** — Real-world applications
