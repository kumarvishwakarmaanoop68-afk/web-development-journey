## Project

### 📝 Smart To-Do List

A browser-based task manager with task creation, completion, deletion, filtering, task statistics, and Local Storage persistence.

## Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Filter: All / Active / Completed
- Task statistics
- Clear completed tasks
- Data stays after refreshing the page using Local Storage
- Responsive layout

## Files

- `index.html` — structure
- `style.css` — styling
- `script.js` — JavaScript logic

## Run

Open `index.html` in a browser.
